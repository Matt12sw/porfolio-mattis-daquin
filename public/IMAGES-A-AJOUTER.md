# Images à déposer

Les captures que tu m'as envoyées dans le chat ne sont **pas** arrivées sous
forme de fichiers dans le projet (elles s'affichent pour moi mais ne sont pas
enregistrées sur le disque). Dépose-les toi-même aux emplacements exacts
ci-dessous — les noms de fichiers sont déjà câblés dans le code. Tant qu'un
fichier est absent, un cadre « capture à venir » propre s'affiche à sa place
(jamais d'image cassée).

## Portrait (page À propos)

```
public/portrait.jpg
```
Format portrait (ratio ~3:4 conseillé). C'est la photo noir & blanc que tu m'as
envoyée.
